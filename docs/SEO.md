# SEO

> SEO strategy (web projects). See `.ai/11-seo.md`.

## On-page
- Unique title (≤ 60 chars) and meta description (≤ 160 chars) per page.
- Canonical URLs.
- Open Graph / Twitter cards.
- JSON-LD structured data.
- One `<h1>`, logical heading hierarchy.
- Clean, lowercase, keyword-relevant URLs.

## Site-level
- `sitemap.xml` maintained and submitted.
- `robots.txt` configured.
- Server-render or SSR/SSG SEO-critical content.
- Core Web Vitals as an SEO signal (see `.ai/10-performance.md`).
